# 组卷助手微信小程序

双击 [双击启动小程序.bat](双击启动小程序.bat) 会打开本机微信开发者工具。本项目是原生微信小程序，不依赖桌面应用进程；题目、模板快照和作答数据均可离线使用。桌面项目其他目录无需改动。

## 生成手机预览二维码

1. 在 [project.config.json](project.config.json) 中把 `appid` 的 `touristappid` 换成你的小程序 AppID（`wx` 开头）。没有正式 AppID 时，可先到 [微信小程序测试号页面](https://mp.weixin.qq.com/wxamp/sandbox?doc=1) 扫码申请测试号，再填入其 AppID。游客模式只能在开发者工具中查看，不能生成可扫码的真机预览。
2. 登录微信开发者工具，使用有该 AppID 开发权限的微信账号。
3. 双击 `双击启动小程序.bat`。脚本会打开项目、调用开发者工具的预览命令，并在此目录生成、打开 `preview-qr.png`。用手机微信扫描即可预览。若尚未登录，脚本会提示在开发者工具登录后重试。

预览码依赖微信开发者工具登录状态和 AppID 权限；它不是永久发布码。扫码预览时不需要本机保持在线，因为当前版本使用离线数据。正式给其他人使用仍需在微信公众平台完成提交审核和发布。

## 当前功能

- 包含桌面数据库中已审核的 8,137 道题，按微信分包限制拆成 11 个离线题库包。
- 首页按真实题库、题型、一级/二级范围和题数筛选；进入独立答题页后，可用左上角返回筛选。
- 跨分包连续答题、答题卡、进度恢复、选择题判分、主观题草稿与自评、错题重练和本机作答历史。
- 使用桌面模板离线随机组卷，整份试卷连续作答。
- 今日待办和专注/休息计时。开始专注后隐藏底部导航、保持屏幕常亮；离开小程序时自动暂停，返回后仍回到专注页，继续计时才可解除锁定。提前结束需确认。
- 底部四个导航入口均有选中与未选中图标。

当前数据是导出时的快照。桌面版后来新增或修改题目时，运行 `.venv/Scripts/python.exe -B if_wechatapps_clickhere/tools/export_questions.py` 更新题库、模板和分包。该脚本只读桌面数据库，只写本文件夹。

桌面版的模板编辑、PDF/DOCX 导入导出、题面图片、知识点图解、桌面宠物、408 实验台、Agent 组卷、服务端学习记录尚未移植。题干中的复杂公式保留文本，少量依赖原卷截图的题需回桌面版查看。小程序的错题/待办存在微信本机存储，不与桌面 SQLite 同步；清理微信数据会清除它们。

如果微信本机存储不可用（例如开发者工具使用游客模式或登录过期），界面会提示进度仅暂存本次运行，仍可继续练习和切换页面。后续保存成功时会补写暂存数据；恢复存储前关闭或重新编译小程序，会丢失这些暂存进度。手机长期使用前需确认本机存储正常。

专注锁定限制在小程序内生效。微信和手机系统仍允许用户切换应用或返回桌面；小程序无法拦截系统手势。尝试离开时本轮会暂停、记录中断次数和离开时长，重新打开后继续显示专注页，需手动继续后才恢复计时。常亮效果以真机微信为准。

## 验证

在此文件夹运行 `node tools/verify-mini.js`，检查题库、答题、组卷、错题，以及专注开始、后台暂停、恢复、结束和解锁。

## 文件

- `app.json`：主页面与分包配置。
- `packages/`：离线题目数据和练习页面。
- `data/catalog.js`、`data/question-index.js`：题库索引与模板。
- `tools/export_questions.py`：从桌面 SQLite 导出快照。
- `tools/start-wechat.ps1`：启动开发者工具并请求预览码。
